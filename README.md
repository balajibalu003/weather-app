## 1. Project Description
Cloud Compass is a modern weather forecasting app built with **React** and **Tailwind CSS**.  
It fetches **current weather conditions** and a **5-day forecast** for any city worldwide using the **OpenWeather API**.  

Key features:  
- Glassmorphism UI design with blurred, semi-transparent cards  
- Animated gradient background for a lively look  
- Responsive layout for desktop and mobile  
- Stores last searched city in localStorage for quick access  
- Clear error handling for invalid city searches or API failures
